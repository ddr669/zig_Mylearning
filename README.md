# Zig language

---

Zig is a general-purpose programming language and 
toolchain for maintaining *robust*, *optimal*, and
*reusable* software.

Often the most efficient way to learn something new 
is to see examples, so this documentation shows how 
to use each of Zig's features. It is all on one page 
so you can search with your browser's search tool.

The code samples in this document are compiled and 
tested as part of the main test suite of Zig.

This HTML document depends on no external files, 
so you can use it offline.

[ficial doc](https://ziglang.org/documentation/master/)
